人物モデルの構築

当研究所では、戦国時代を中心とした歴史上の人物を対象に、史料の分析結果を反映したAI人物モデルの構築を進めています。現在、以下の3名について基礎検証用モデルの構築を完了しています。

BASE MODEL COMPLETED

織田信長

関連史料をもとに、発言傾向や判断に関する特徴を整理した人物モデル。対話シミュレーションを通じた応答傾向の検証を継続しています。

BASE MODEL COMPLETED

豊臣秀吉

人物に関する記録と時代背景を分析し、基礎的な人物特性を反映したモデルを構築しています。

BASE MODEL COMPLETED

徳川家康

史料に記録された言動や判断に着目し、対話による基礎検証を行うためのモデルを構築しています。

検証の取り組み

史料との照合

モデルの応答を関連史料や事前の分析結果と照合し、人物像との整合性を確認します。

応答傾向の記録

質問内容や対話条件とともに応答を記録し、同様の条件下での傾向を検証します。

想定外の応答の検討

事前の想定と異なる応答についても、発生条件と内容を記録し、追加検証の対象としています。

今後の研究について

現在は、構築済みモデルの応答傾向を継続的に検証するとともに、人物像の再現性を高めるための分析を進めています。対象人物や検証項目については、資料の状況と研究成果を踏まえ、順次検討していく予定です。
